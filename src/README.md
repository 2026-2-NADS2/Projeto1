### Módulo do sistema 1 – Administrador

| **Aluno(s) Responsável(veis)** | Anna Paula Alves Silva, Laura Rayssa Araújo, Rafaela Carvalho Barcos Mello |
| :--- | :--- |
| **Ferramenta utilizada** | Claude (Anthropic) |
| **Versão/modelo** | Sonnet 5.5 e Opus 5.5 |
| **Disciplina / Trabalho** | Projeto Interdisciplinar 4U – Módulo do Administrador |
| **Finalidade de uso** | Apoio na construção das telas do administrador em React com dados fictícios. Usamos o Claude para tirar dúvidas e revisar partes do código dos componentes, da navegação entre as telas e da criação da carga de dados fictícios. |
| ***Prompts* principais utilizados** | "Como colocar o campo de notificações?"<br>"Verifique esses layouts de inspiração para as telas de Cadastros e Relatórios."<br>"Como faço para a administradora liberar o acesso e a pessoa receber o e-mail para criar a senha?"<br>"Como funciona a exportação em Excel?" |
| **Trechos ou entregas afetadas** | Telas Dashboard, Cadastros, Acompanhamentos, Bimestres e Relatórios do administrador e as rotas da API que elas usam: cadastros com busca, filtros e paginação, liberação e desativação de acesso, vínculos de turma, revisão, devolução e publicação dos registros, indicadores e exportação para Excel. O código foi elaborado com apoio do Claude e foi testado e revisado por nós antes da entrega. |
